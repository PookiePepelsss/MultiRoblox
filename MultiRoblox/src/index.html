Multi-Instance
Multiple Roblox instances
Holds the singleton mutex so multiple clients run at once. Turning this off releases it and lets Roblox go back to allowing only one client.
Anti-AFK
Keep instances active
Taps a benign key into every running instance before Roblox's ~20-minute idle kick.
Tap interval
How long an instance can sit idle before it gets tapped. Stays under the ~20-minute kick.
bolt 19 min
Relaunch on Disconnect
Relaunch on disconnect
If a running instance disconnects unexpectedly, relaunch that same account back into the same game automatically.
Memory
Trim RAM
Frees idle memory from every running instance without touching or slowing the game.
Auto trim
Trims every running instance automatically on an interval.
Trim interval
How often auto trim runs while instances are open.
memory 5 min
CPU Priority
Lower priority when multiple accounts run
Once more than one account is running, sets all of them to Below Normal priority so the OS scheduler doesn't split CPU evenly across idle instances. Reverts to Normal automatically when back down to one.
